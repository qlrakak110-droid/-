# 존재와 공허 (정령의 섬)

하늘이 갈라진 섬에서 정령을 모아 **존재의 전설 엔시아**와 **공허의 전설 니힐로스**를 만나는
오리지널 3D 정령 수집 RPG입니다. 브라우저에서 바로 실행됩니다(Three.js, 설치 없음).

* 실행: `spirit-island/index.html` 을 브라우저로 열기 (첫 실행 때 인터넷에서 Three.js 를 받아옵니다)
* PC: WASD/방향키 이동 · Shift 달리기 · E/Space 상호작용 · 드래그(또는 Q/R) 시점 회전 · 휠 확대 · P 정령 · B 가방 · Esc 설정
* 모바일: 왼쪽 스틱 이동 · A 버튼 상호작용 · 빈 화면 끌어 시점 회전 · 두 손가락 확대
* 저장: 전투가 끝날 때와 중요한 순간마다 브라우저(localStorage)에 자동 저장

## 이야기

태초에 모든 것을 빚는 **존재(엔시아)** 와 모든 것을 되돌리는 **공허(니힐로스)** 가 있었고, 두 힘이 맞물린 자리에
'경계의 섬'이 태어났습니다. 어느 날 밤 하늘에 금이 가고, 섬 곳곳에 공허의 균열이 열립니다.

1. **윤슬마을**: 장로 무연에게 첫 정령을 받습니다 (화르르 / 물롱 / 새싹뿔).
2. **세 균열**: 동쪽 불씨 언덕(하람) · 서쪽 번개 습지(이든) · 북쪽 그림자 숲길(세레나). 수호자를 이기면 균열이 닫히고
   **존재의 파편**을 얻습니다. 균열이 닫힐 때마다 하늘의 금이 가늘어지고, 보랏빛으로 물든 땅이 회복됩니다.
3. **근원의 제단**: 파편 셋을 바치면 하늘이 찢어지며 **니힐로스**가 내려옵니다. 그 뒤에는 빛기둥 속에서
   **엔시아**가 내려옵니다. 둘 다 근원결정으로 봉인할 수 있습니다.
4. 엔딩 뒤에는 균열이 닫히고 섬에 새벽이 옵니다. 그 뒤로는 자유 탐험과 도감 채우기(16종)를 할 수 있습니다.

## 시스템

| 항목 | 내용 |
|---|---|
| 정령 | 16종 (스타터 3종 + 진화 3종, 야생 8종, 전설 2종). 모두 코드로 만든 툰 셰이딩 3D 모델이며 외곽선, 눈 깜빡임, 걷기·떠다니기 애니메이션이 있음 |
| 속성 | 일반 · 불 · 물 · 풀 · 번개 · 대지 · 빛 · 그림자 · **존재** · **공허** (공허 ↔ 존재 / 빛 ↔ 공허 / 그림자 ↔ 존재 상성) |
| 전투 | 턴제. 속도 순서, 상성, 자속 보정, 치명타, 화상·마비, 능력 단계 변화, 흡수, 능력 초기화(허무의손길) |
| 성장 | 경험치·레벨업, 레벨에 따라 기술 습득(4개 넘으면 잊을 기술 선택), Lv.16 진화 연출 |
| 봉인 | 봉인결정 / 근원결정. HP가 낮고 상태 이상일수록 잘 잡히며, 결정이 1~3번 흔들린 뒤 결과가 나옴 |
| 연출 | 블룸 조명, 그림자, 물가 거품이 있는 바다 셰이더, 바람에 흔들리고 플레이어를 피해 눕는 풀숲, 하늘의 공허 균열 셰이더, 반딧불, 전설 등장 컷신, 기술마다 다른 이펙트 13종 |
| 소리 | WebAudio로 합성하는 배경음(마을 · 전투 · 공허 · 존재 · 타이틀) 과 효과음 |
| 그래픽 설정 | 높음(블룸·그림자·풍성한 풀) / 낮음(휴대폰 절약). 작은 터치 화면에서는 낮음이 기본값 |

## 코드 구조

```
spirit-island/
  build.py          src/*.js 를 순서대로 이어 붙여 index.html 한 파일로 만듦
  index.html        빌드 결과 (바로 실행)
  src/template.html 화면 구성(HUD, 대화창, 전투 UI, 메뉴)과 스타일
  src/00_core.js    렌더러·블룸, 트윈, 입력(키보드·스틱·드래그), 툰/외곽선/공허 재질, 파티클, 신스 사운드
  src/01_data.js    속성 상성표, 기술 36종, 정령 16종, 아이템, 능력치 공식, 출현 테이블
  src/02_models.js  정령·전설·사람 3D 모델과 애니메이션 리그, 도감 아이콘 렌더러
  src/03_world.js   섬 지형·바다·하늘·나무·풀숲·마을·제단·균열, 이동·충돌·카메라
  src/04_battle.js  전투 무대, 턴 엔진, 기술 이펙트, 봉인, 경험치, 진화
  src/05_game.js    저장, 대화, 스토리 이벤트, NPC, 메뉴(정령·가방·도감·설정), 메인 루프
```

수정한 뒤에는 `python3 spirit-island/build.py` 로 `index.html` 을 다시 만들면 됩니다.
