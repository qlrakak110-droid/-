# 존재와 공허 (정령의 섬)

하늘이 갈라진 섬에서 정령을 모아 **존재의 전설 엔시아**와 **공허의 전설 니힐로스**, 그리고 섬 곳곳에 깨어나는
네 전설을 만나는 오리지널 3D 정령 수집 RPG입니다. 브라우저에서 바로 실행됩니다(Three.js, 설치 없음).

* 실행: `spirit-island/index.html` 을 브라우저로 열기 (첫 실행 때 인터넷에서 Three.js 를 받아옵니다)
* PC: WASD/방향키 이동 · Shift 달리기 · E/Space 상호작용 · 드래그(또는 Q/R) 시점 회전 · 휠 확대 · P 정령 · B 가방 · Esc 설정
* 모바일: 왼쪽 스틱 이동 · A 버튼 상호작용 · 빈 화면 끌어 시점 회전 · 두 손가락 확대
* 저장: 전투가 끝날 때와 중요한 순간마다 브라우저(localStorage)에 자동 저장

## 이야기

태초에 모든 것을 빚는 **존재(엔시아)** 와 모든 것을 되돌리는 **공허(니힐로스)** 가 있었고, 두 힘이 맞물린 자리에
'경계의 섬'이 태어났습니다. 어느 날 밤 하늘에 금이 가고, 섬 곳곳에 공허의 균열이 열립니다.

1. **윤슬마을**: 장로 무연에게 첫 정령을 받습니다 (화르르 / 물롱 / 새싹뿔).
2. **세 균열**: 동쪽 불씨 언덕(하람) · 서쪽 번개 습지(이든) · 북쪽 그림자 숲길(세레나). 수호자를 이기면 균열이 닫히고
   **존재의 파편**을 얻습니다. 균열이 닫힐 때마다 하늘의 금이 가늘어지고, 보랏빛으로 물든 땅이 회복됩니다.
3. **근원의 제단**: 파편 셋을 바치면 하늘이 찢어지며 **니힐로스**가 내려옵니다. 그 뒤에는 빛기둥 속에서
   **엔시아**가 내려옵니다. 둘 다 근원결정으로 봉인할 수 있습니다.
4. 엔딩 뒤에는 균열이 닫히고 섬에 새벽이 옵니다. 자유 탐험을 하며 남은 전설과 도감(20종)을 채웁니다.

## 전설의 정령 6마리

| 정령 | 주제 · 속성 | 만나는 곳 · 조건 | 전용 기술 |
|---|---|---|---|
| 니힐로스 | 공허 · 공허 | 근원의 제단 (파편 3개) | 공허붕괴 |
| 엔시아 | 존재 · 존재 | 근원의 제단 (니힐로스 이후) | 창세의빛 |
| 아스테리온 | 별 · 빛/존재 | 북동쪽 별빛 봉우리 (균열 1개를 닫은 뒤) | 유성우 |
| 아비세아 | 심해 · 물/공허 | 서쪽 고래울음 바위 (균열 2개를 닫은 뒤). 평소엔 앞바다에서 물 위로 솟구쳐 오름 | 심연해일 |
| 단하 | 여명 · 불/존재 | 동쪽 해돋이 언덕 (엔딩 뒤). 평소엔 섬 하늘을 날아다님 | 여명의포효 |
| 리미나 (환상) | 경계 · 존재/공허 | 남쪽 경계의 모래톱 (엔시아·니힐로스를 모두 봉인한 뒤) | 경계붕괴 |

전설마다 등장 컷신, 전용 경기장(공허 · 존재 · 별밤 · 심해 · 구름 위 새벽 · 반은 빛이고 반은 어둠인 경계), 전용 배경음이 있습니다.
전설이 깨어나면 화면 왼쪽 위 목표 칸에 "전설의 기척"이 표시되고, 그 장소 위에 표식이 뜹니다.

## 시스템

| 항목 | 내용 |
|---|---|
| 정령 | 20종 (스타터 3종 + 진화 3종, 야생 8종, 전설 6종). 모두 코드로 만든 3D 모델이며 외곽선, 눈 깜빡임, 걷기·떠다니기 애니메이션이 있음 |
| 속성 | 일반 · 불 · 물 · 풀 · 번개 · 대지 · 빛 · 그림자 · **존재** · **공허** (공허 ↔ 존재 / 빛 ↔ 공허 / 그림자 ↔ 존재 상성), 전설은 복합 속성 |
| 전투 | 턴제. 속도 순서, 상성, 자속 보정, 치명타, 화상·마비, 능력 단계 변화, 흡수, 능력 초기화(허무의손길) |
| 성장 | 경험치·레벨업, 레벨에 따라 기술 습득(4개 넘으면 잊을 기술 선택), Lv.16 진화 연출 |
| 봉인 | 봉인결정 / 근원결정. HP가 낮고 상태 이상일수록 잘 잡히며, 결정이 1~3번 흔들린 뒤 결과가 나옴 |
| 소리 | WebAudio로 합성하는 배경음(마을 · 전투 · 타이틀 · 전설 6곡)과 효과음(포효, 고래 울음, 유성 등) |

## 그래픽

* **렌더링**: HDR 렌더 + 멀티샘플 안티에일리어싱, 블룸, ACES 톤매핑, 실시간 그림자
* **후처리**: 태양 빛줄기, 색보정, 비네팅, 필름 그레인, 가장자리 색수차
* **캐릭터**: 툰 셰이딩 + 림라이트 + 애니풍 하이라이트. 아스테리온은 몸 안에 우주가 비치는 셰이더, 리미나는 반은 진주빛·반은 공허인 날갯짓 셰이더
* **하늘·바다**: 해 방향으로 빛나는 절차적 구름층, 하늘의 공허 균열, 별과 달. 바다는 하늘을 비추고 물가에 거품이 있음
* **지형**: 바람에 흔들리는 나무, 섬 전체의 잔디와 플레이어를 피해 눕는 풀숲, 반딧불
* **전투 연출**: 타격 순간 멈춤(히트스톱), 화면 충격파 왜곡, 전설 등장과 필살기의 시네마 레터박스·슬로모션·카메라 워크, 기술 이펙트 17종
* **그래픽 설정**: 높음 / 낮음. 작은 터치 화면에서는 낮음(후처리·잔디 끔)이 기본값

## 코드 구조

```
spirit-island/
  build.py          src/*.js 를 순서대로 이어 붙여 index.html 한 파일로 만듦
  index.html        빌드 결과 (바로 실행)
  src/template.html 화면 구성(HUD, 대화창, 전투 UI, 메뉴)과 스타일
  src/00_core.js    렌더러·후처리(블룸, 시네마틱 패스), 히트스톱, 트윈, 입력, 툰/외곽선/공허 재질, 파티클, 신스 사운드
  src/01_data.js    속성 상성표, 기술 45종, 정령 20종, 아이템, 능력치 공식, 출현 테이블
  src/02_models.js  정령·전설·사람 3D 모델과 애니메이션 리그, 우주·가오리 셰이더, 도감 아이콘 렌더러
  src/03_world.js   섬 지형·바다·하늘·나무·잔디·마을·제단·균열·전설의 거처, 이동·충돌·카메라
  src/04_battle.js  전투 무대(8종), 턴 엔진, 기술 이펙트, 봉인, 경험치, 진화
  src/05_game.js    저장, 대화, 스토리 이벤트, 전설 등장, NPC, 메뉴(정령·가방·도감·설정), 메인 루프
```

수정한 뒤에는 `python3 spirit-island/build.py` 로 `index.html` 을 다시 만들면 됩니다.
